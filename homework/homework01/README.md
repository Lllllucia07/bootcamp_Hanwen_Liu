# Homework 01 - Project Framing

## Project Scoping

This project examines whether an ETF trading strategy that performed well historically is likely to remain effective in the future. The primary stakeholder is a portfolio manager who must decide whether to continue allocating capital to the strategy. Historical performance alone may not be sufficient because the strategy could perform differently across changing market conditions.

The analysis will evaluate the strategy using measures such as annualized return, volatility, Sharpe ratio, and maximum drawdown. The project will also compare performance across different time periods and market environments. A useful outcome would be evidence showing whether the strategy's risk-adjusted performance is relatively stable or highly dependent on a particular historical period.

## Goal

Evaluate whether an ETF trading strategy has persistent risk-adjusted performance.

## Lifecycle

Data collection → Data cleaning → Strategy construction → Backtesting → Risk analysis → Performance evaluation

## Deliverables

- Jupyter Notebook
- Performance visualizations
- Risk metrics
- Final recommendation for the portfolio manager
